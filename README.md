# synths.js

[![MIT licence](https://img.shields.io/badge/licence-MIT-green)](LICENSE)

synths.js is for making sounds and music in plain JavaScript: synths, samples, effects and tracker songs, for games and for the fun of it. It is the sound sibling of [pictures.js](https://github.com/johnwylie70/pictures.js), designed for projects made in [Circuitry Studio](https://www.circuitry.dev), and it runs anywhere a browser does.

Nothing here is ready to use yet.

Prefer Python? [synths](https://github.com/johnwylie70/synths-py) is the same library for Python.

The sound engine itself is [synths-core](https://github.com/johnwylie70/synths-core).
